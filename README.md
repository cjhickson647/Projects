# Engineering Projects

This repository contains selected technical projects from my coursework, research, student organizations, and personal engineering work at Worcester Polytechnic Institute.

My projects focus primarily on robotics, embedded systems, electronics, RF communications, autonomous systems, and computer vision. Each folder documents the project goals, my individual contributions, major design decisions, technical challenges, and results. Where appropriate, I also include source code, CAD files, schematics, images, and other supporting material.

Some projects are still actively being developed or documented. For those, I may include a brief project summary before a full technical writeup is available rather than publishing incomplete documentation.

If you found this repository through my resume and would like additional technical details about a project, feel free to contact me at [cjhickson@wpi.edu](mailto:cjhickson@wpi.edu).

Thanks for taking the time to look through my work.
